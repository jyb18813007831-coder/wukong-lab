# 悟空 Lab（wukong-lab）

学实验 · 排故障 · 一起变强。

面向零基础新生与有经验实验人员：**学标准操作、查失败原因、图文贡献经验**。  
双轨：**GitHub = 协议与贡献底仓**；**微信小程序 = 学习与交互排错**。

> 角色设定延续「实验室小悟空」——72 变，对应多实验大类、多形态交付。远期步骤 ID 可接入实验智能体 / 操作臂。

## 四模块

1. [新生入组](docs/01-onboarding/) — 通用习惯与精细操作对照  
2. [生物安全](docs/02-biosafety/) — 化学品 / 尖锐物 / 气溶胶 / 伦理知情  
3. [紧急应对](docs/03-emergency/) — 止血、溢洒、眼睛进液、火灾疏散  
4. [具体实验](docs/04-experiments/) — **v0 做透 Western Blot**；其它大类占位
